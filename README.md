# Brent-WTI Commodity Analysis | Python
A growing portfolio of quantitative commodity market models built during the IBM Data Science Professional Certificate. All models are fed by a centralised data pipeline covering 15 commodities from 2019 to present.
Models included:

Spread Analysis — Brent-WTI daily spread with 30 day rolling average and volatility bands
Drawdown Analysis — Spread drawdown from peak with maximum drawdown annotation
Volatility System — 30/60/90 day rolling volatility with high/normal/low regime classification
Monte Carlo Simulation — 1000 path simulation with 90 day outlook and percentile bands
Forward Curve — WTI futures curve structure identifying contango and backwardation
Mean Reversion Model — Z score based signal system with historical buy/sell signal tracking
Ceasefire Event Study — Cross commodity performance analysis around the June 17 2026 Middle East ceasefire announcement

Tools: Python, pandas, NumPy, matplotlib, yfinance
Data: 15 commodities across Energy, Metals, Softs, Grains and Macro from 2019 to present
